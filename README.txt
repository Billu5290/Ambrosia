AMBROSIA FAMILY RESTRO BAR & AC DINING WEBSITE

Files:
- index.html: complete responsive website (HTML, CSS, JavaScript included)
- assets/: supplied restaurant/menu photos

How to preview:
1. Extract the ZIP file.
2. Open index.html in a browser. Internet connection is needed for Google Fonts and the embedded Google Map.

How to publish:
- Netlify: drag the extracted ambrosia-website folder (or its contents) into Netlify Drop.
- GitHub Pages: upload index.html and the assets folder to a repository, then enable Pages in repository settings.

Before publishing, please verify menu prices and spellings against the current printed menu. Some prices were transcribed from phone photos and may need correction. The website is a static site; WhatsApp and phone links open the visitor's messaging app or dialler. No online booking backend is connected.
